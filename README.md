# Vistra Arcade

Minijuegos originales para el navegador, hechos con HTML, CSS y JavaScript sin dependencias.

## Juegos

- **Buscaminas:** niveles Principiante (8×8, 10 minas), Intermedio (16×16, 40), Experto (16×30, 99) y Personalizado. Primer clic seguro, apertura de vecinas y top 10 de récords personales por nivel (guardados en el navegador).

## Ejecutar en local

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
npx serve .
```

## Añadir un juego

1. Crea una carpeta en `games/<nombre>/` con su `index.html`.
2. Añade una tarjeta enlazándola en el `index.html` principal.
